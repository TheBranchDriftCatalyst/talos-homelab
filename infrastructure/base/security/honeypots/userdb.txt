# Cowrie credential database. THIS FILE EXISTING IS THE POINT.
#
# Without it cowrie falls back to _USERDB_DEFAULTS (src/cowrie/core/auth.py):
#     root:x:!root      <- REJECTS the single most common password
#     root:x:!123456    <- REJECTS the second most common
#     root:x:*          <- ACCEPTS anything else
#     phil:x:*
# A server that refuses root:root and root:123456 while accepting root:hunter2 behaves like
# nothing real, and the test costs ONE connection with no shell access. It is the cheapest
# pre-auth fingerprint of a cowrie honeypot there is. Verified 2026-09-20: we were running the
# defaults, and `root/mysql` is what let the operator who uploaded the backdoored `sshd` in.
#
# Format: username:uid(x = any):password
#   !pass  = explicitly REJECT this password
#   *      = accept ANY password  <- never use this, it recreates the oracle
#
# The list below is a plausible weak-password set for a neglected Ubuntu box: broad enough that
# real bots still get in (we WANT them in -- that is how samples are captured) but a fixed,
# finite list, so probing it looks like a weak box rather than a wildcard.
# Passwords chosen from credentials our own honeypot actually observes being tried.
